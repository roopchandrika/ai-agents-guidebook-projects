# Sample knowledge base

Replace or add your own .txt, .md or .pdf files in this folder, then run `python ingest.py`.

## AI Agents
An AI agent is an autonomous system that perceives its environment, reasons about it,
and takes actions using tools to achieve a goal. Unlike a plain LLM, which only produces
text from its training data, an agent can plan, call tools, observe results and iterate.

## RAG
Retrieval-Augmented Generation (RAG) gives an LLM access to external knowledge by retrieving
relevant documents from a vector database and adding them to the prompt.

## Agentic RAG
Agentic RAG lets an agent decide *where* to retrieve context from — for example a private
vector database or a live web search — instead of always using one fixed retriever.
